# Bejad Challenges — تحديات بيجاد 🎮

لعبة موبايل من نوع التحديات والمراحل، مبنية بتقنية HTML5 وتعمل على أي متصفح جوال بدون أي تثبيت.

## طريقة التشغيل

افتح الملف `index.html` في متصفح الهاتف، أو ارفع المجلد على أي استضافة ثابتة (GitHub Pages مثلاً) وافتح الرابط من الجوال.

## المميزات

- **20 مستوى** تتدرج في الصعوبة من السهل جدًا إلى الصعب، ولا يفتح المستوى التالي إلا بعد إنهاء الحالي.
- **6 أنواع تحديات** تتناوب عبر المراحل:
  - 🎯 اضغط الأهداف قبل اختفائها
  - 🪙 اجمع العملات وتجنب القنابل
  - ⚡ سرعة رد الفعل (اضغط عند الأخضر فقط)
  - 🧠 أسئلة حسابية سريعة
  - 🔷 تحدي الذاكرة (إعادة تسلسل المربعات)
  - 🌠 تجنب العقبات المتساقطة بتحريك الإصبع
- **نظام نقاط**: نقاط لكل إنجاز + مكافأة سرعة على الوقت المتبقي، مع أعلى نتيجة وأفضل نتيجة لكل مستوى.
- **نظام وقت**: عداد وشريط وقت واضح، وانتهاء الوقت يعني خسارة المحاولة.
- **3 قلوب ❤️**: خسارة قلب عند كل فشل، وشاشة Game Over عند نفادها مع إمكانية إعادة المحاولة.
- **عملات 🪙**: تُكسب عند الفوز وتظهر في الشاشة الرئيسية (جاهزة لاستخدامها مستقبلًا في فتح أشياء جديدة).
- **مؤثرات**: أصوات مولّدة بـ Web Audio (ضغط/فوز/خسارة/عملات)، موسيقى خلفية هادئة، ومؤثرات بصرية عند جمع النقاط — كلها قابلة للإيقاف من الإعدادات.
- **حفظ تلقائي** عبر localStorage: المستوى، النقاط، العملات، والإعدادات — يستمر التقدم بعد إغلاق التطبيق.
- **تصميم موبايل**: واجهة عربية RTL، أزرار كبيرة، دعم مختلف الشاشات و safe areas.

## بنية الملفات

- `index.html` — اللعبة كاملة في ملف واحد (HTML + CSS + JavaScript، بدون أي مكتبات خارجية).
- `game.html` — نفس المحتوى بصيغة مناسبة للنشر كـ Artifact.

## إضافة مستويات أو تحديات جديدة

- لزيادة عدد المستويات: عدّل الثابت `LEVEL_COUNT`.
- لإضافة نوع تحدٍّ جديد: أضف دالة في الكائن `CHALLENGES` واسمها في المصفوفة `TYPES` مع بياناته في `TYPE_INFO`.
